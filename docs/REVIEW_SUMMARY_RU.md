# Итог ревью и упаковки

## Что уже доказано на development-периоде

- CatBoost predictive graph структурно не похож на Pearson: он направленный,
  почти невзаимный и имеет малое пересечение рёбер с корреляционной сетью.
- Текущее состояние CatBoost-графа дало лишь микроскопический численный выигрыш
  над HAR-RV: QLIKE `-7.145484` против `-7.144596`.
- Этот выигрыш не был статистически устойчивым.
- Dynamic graph features не дали устойчивого улучшения ни для Pearson, ни для
  ElasticNet, ни для CatBoost.
- Удаление IMOEX market factor сильно изменило топологию сети, но не позволило
  превзойти residual HAR-RV.
- Это содержательный отрицательный результат: новая сетевая структура есть, но
  её дополнительный однодневный forecasting signal слабее ошибки оценки.

Все эти выводы относятся только к данным до 2026-08-10. Confirmatory-результатов
пока нет.

## Что исправлено в коде

- Confirmatory run больше не читает изменяемый development selection.
- Freeze нельзя перезаписать через `--force`.
- Forecast требует manifest v02 и проверяет hashes кода, протокола и design.
- Неполный последний 20-дневный block корректно достраивается.
- Assembly сверяет модели с полной ожидаемой выборкой, а не только друг с
  другом.
- Sealed prediction artifact не может содержать target или loss.
- Residual shards достраиваются при появлении новых дат.
- IMOEX downloader обновляет последний месяц и проверяет границы старых cache.
- История обучения явно ограничена текущим temporal segment.
- v10.1 исключает две точные пары alias-признаков из ridge design, не меняя
  исторический v10.

## Что нельзя завершить без локального `data_v02`

1. Пересчитать v10.1 alpha на исходных 60 validation dates.
2. Создать настоящий локальный v10.1 freeze и manifest.
3. Сверить восстановленные из диалога числа с машинными CSV.
4. Построить публикационные графики.
5. Продолжать sealed holdout по новым датам.

## Как это использовать для карьеры

Проект показывает сразу несколько навыков, полезных для Quant Research и ML/DS
стажировок: временная валидация, защита от leakage, CatBoost и регуляризация,
financial econometrics, network analysis, статистические тесты, устойчивые
batch pipelines и честное объяснение отрицательного результата.

В будни этот проект занимает только research/GitHub-блок общего плана: одна
задача по алгоритмам, одна тема теории, маленький research commit, английский и
немецкий. Выходные остаются для отдыха и шитья брюк.
