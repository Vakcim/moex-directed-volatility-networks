# No-cost dissemination plan

The project can create career value without paying a conference fee.

1. Publish the cleaned code and documentation on GitHub after the privacy and
   license checklist.
2. Create a free preprint only after data-rights and supervisor/coauthor checks.
3. Record a short technical walkthrough and link it from the README.
4. Submit to free seminars, reading groups, university workshops or venues with
   an explicit fee waiver. Verify current terms before submitting.
5. Treat any paid conference, including a previously discussed conference
   option, as out of scope unless the full cost is waived or funded externally.

The strongest public story is not “CatBoost wins.” It is: a rigorously
constructed predictive network differs from a correlation network, yet the
extra structure does not robustly beat a strong HAR benchmark. That shows
model validation judgment as well as implementation skill.
